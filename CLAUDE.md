# RP Psyche

Стресс и рассудок для RP-сервера (`rppsyche`): что давит, что успокаивает и как это видит сам игрок. Семейство RP/FL/S5, Forge 1.20.1, Java 17. Отвечать по-русски.

## Прежде чем что-то добавлять
1. `../_family/FAMILY_MAP.md`, раздел 3 «Куда это положить» — нет ли готового механизма в RP Core или другого мода для этой задачи.
2. `docs/MAP.md`, раздел 4 — рецепт для твоего случая и образец, с которого списать.
3. `docs/INDEX.md` — поиск по слову: нет ли уже такого класса, события, команды.

Новый класс, пакет, пакет сети, команда, ключ конфига или поле состояния — обнови `docs/MAP.md` в том же
коммите и пересоздай указатель: `python ../_family/tools/mapgen.py "RP Psyche"`.

## Нельзя
- Менять ключ данных игрока `rppsyche:psyche` и имена полей в `PsycheData.save/load`, ключи и границы `rppsyche-server.toml` (имя ключа = имя поля `Settings`).
- Переставлять шаги в `PsycheService.step`: от порядка зависит результат.
- Импортировать `faygolover.rpmedicine`: тело читается через `integration/BodyCompat` (RP Core).
- Запускать `scripts/gen_lang.py`: отстал, сотрёт переводы.
- Прямые импорты и отражение в другие моды семейства — только через RP Core (исключения: `../_family/links_allow.txt`).
- Push, выпуск сборки, правки живого сервера — только по прямому слову Алекса. Коммиты локальные.

## Команды
```
gradlew.bat build                                        # jar в build/libs
python ../_family/family.py verify --tests "RP Psyche"   # компиляция, связи, игровые тесты (7)
```
